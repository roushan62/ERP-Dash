# Fonts

Place the open-source **Inter** (or **Noto Sans**) font files here (`.woff2`, `.ttf`).

The app falls back to `Segoe UI` when the font is not present, so this folder is
optional. To bundle Inter, download the files from
https://rsms.me/inter/ and add an `@font-face` rule in
`src/styles/typography.css`.
